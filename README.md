# AutoMine — Fabric-мод

Готовые Java-файлы лежат в `src/main/java/ru/threel/automine/`.
У меня нет доступа к репозиториям Fabric/Minecraft в песочнице, поэтому
build.gradle/gradle.properties под твою версию 26.2 нужно взять с генератора
шаблонов — сам код от этого не зависит.

## Сборка

1. https://fabricmc.net/develop/template/ → выбери Minecraft **26.2**,
   Loader/Yarn последние, скачай архив шаблона.
2. Распакуй шаблон, удали из него `src/` и `fabric.mod.json` — вставь на их
   место содержимое этой папки (`src/` целиком + `fabric.mod.json`).
3. В `gradle.properties` шаблона проверь `mod_version` / `maven_group` — можно
   оставить как есть.
4. Собери:
   ```
   ./gradlew build
   ```
   Готовый `.jar` — в `build/libs/`.
5. Кинь его в `.minecraft/mods/` вместе с Fabric API (для той же версии) и
   остальными модами сервера.

## Использование

- Апостроф (`'`) — открыть окно выбора блоков.
- В окне: поиск по имени, чекбоксы `[x]/[ ]` на нужные блоки, кнопка
  "Автодобыча: ВКЛ/ВЫКЛ".
- Пока включено — персонаж сам идёт к ближайшему выбранному блоку в радиусе
  24 блоков и копает его.

## Важно

- Навигация простая (иду прямо + прыгаю на препятствие), не A*-путь как в
  Baritone — по открытой местности ок, в сложных пещерах может застревать
  (тогда через 15 сек сама берёт другую цель).
- Не копает блок больше чем на 1 ниже уровня ног, не подходит и не копает
  рядом с лавой/водой/огнём/кактусом/магмой/слаймом.
- Мод клиентский, античиты некоторых серверов могут палить резкие повороты/
  движение — используй на свой риск, это ваш сервер.
